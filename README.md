# Brightwell - Dental Clinic HTML Template

Brightwell is a Bootstrap 5 HTML template for dental clinics, family dentists and orthodontists. It has 10 pages, including a price list, a before/after smile gallery and an online booking form with time slots.

## Features

- 10 HTML pages, Bootstrap 5, responsive
- Before/after drag slider with category filter
- Booking form: office, service, dentist, date and free times
- "Open now / Closed" badge that reads your opening hours
- Pricing page with price list, membership plans, payment plans and insurance
- New patient page with first visit steps and intake form
- Two office locations with hours and map
- Emergency bar in the header
- Reviews slider (Swiper), AOS animations, Bootstrap Icons
- Self-hosted Plus Jakarta Sans font
- HTML documentation

## Pages

index.html, about.html, services.html, service-single.html, smile-gallery.html, pricing.html, new-patients.html, appointment.html, contact.html, 404.html
